# 当前记忆方案真实模型 A/B 评测

## 评测口径

2026-09-10 使用项目本地配置的 `qwen3.7-max` 完成固定数据集真实模型评测。数据集包含 8 个一般用户任务组，共 16 个用户轮次；任务组长度为 1～3 问，覆盖基金概况、区间指标、历史净值、实时行情、季报检索和双基金比较。

- A（无记忆）：每轮创建新会话，问题包含完整基金和参数；没有历史消息、跨轮小便签或事实卡可复用。
- B（当前方案）：每个任务组复用一个会话，后续问题采用“它、同期、刚才、这两只”等自然追问；启用最近两轮/3000 Token 双门限、结构化会话小便签、TTL 和按问题检索的基金分类事实记忆。
- A/B 各运行 16 个用户轮次，共 32 轮。工具数据使用确定性本地 Fixture，LLM 使用真实模型。
- Token 由 Spring AI ChatModel 观测器累计一个用户轮次内的全部 ReAct 模型调用；质量通过要求回答成功并包含预期类型 Evidence。

## 总体结果

| 指标 | A：无记忆 | B：当前方案 | 变化 |
|---|---:|---:|---:|
| 用户轮次 | 16 | 16 | — |
| 模型调用 | 37 | 26 | 降低 29.73% |
| Prompt Token | 94,553 | 58,617 | 降低 38.01% |
| Completion Token | 21,110 | 16,501 | 降低 21.83% |
| 总 Token | 115,663 | 75,118 | 降低 35.05% |
| 工具调用 | 24 | 10 | 降低 58.33% |
| 重复工具调用 | 7 | 0 | 降低 100% |
| 质量通过率 | 81.25% | 87.50% | 提高 6.25 个百分点 |
| 有效事实复用率 | — | 87.50% | 7 / 8 个追问机会 |

总 Token 绝对减少 40,545。

## 分场景结果

| 场景 | A 总 Token | B 总 Token | 变化 | 工具调用变化 |
|---|---:|---:|---:|---:|
| 单问 | 9,045 | 9,093 | 增加 0.53% | 0% |
| 连续任务首问 | 38,378 | 45,491 | 增加 18.53% | 0% |
| 连续追问 | 68,240 | 20,534 | 降低 69.91% | 降低 100% |

结果符合设计预期：单问没有历史事实可以复用，Token 基本持平；当前方案的主要收益来自连续追问。8 个追问中，B 组没有再次调用外部工具，Prompt Token 降低 74.66%，总 Token 降低 69.91%。连续任务首问的增加主要来自真实模型调用轮数波动（A 为 13 次、B 为 14 次），两组该子集质量均为 100%。

## 可引用结论

在固定 8 任务组、A/B 各 16 轮的真实模型评测中，当前分层记忆方案相较无记忆基线将 Prompt Token 降低 38.01%、总 Token 降低 35.05%、工具调用降低 58.33%；连续追问子集总 Token 降低 69.91%，质量通过率由 81.25% 提升至 87.50%。

该结果属于单次固定数据集小样本评测，模型输出存在随机性。用于简历时应保留“固定数据集真实模型 A/B”限定，不应表述为所有线上流量的稳定收益。
