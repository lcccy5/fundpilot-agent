# fund-analytics 与 fund-scheduler 可读性审计

范围只包括 `fund-analytics`、`fund-scheduler` 的主代码和测试，以及本说明。生产行为没有为了测试而改写。记录、枚举上由编译器生成、源码里没有方法体的访问器没有另写注释。

## 已处理

挤在一行里的分支、赋值和返回已拆开，公开名称未改：

- 持仓投影的买入、卖出和冲正分支
- 货币加权收益率的二分与净现值
- 时间加权收益率的连乘提前返回
- 集中度对 null 列表和正市值的筛选
- 覆盖率阈值的嵌套条件
- 净值观测、净值序列构造里的校验
- 指标计算里样本不足、零波动和非有限数值的返回
- 知识入库工人的轮询、续租和关闭

每个手写类型、构造器和方法都补了中文 JavaDoc，说明职责，并以失败或边界行为收尾。百分比仍用小数，`0.12` 表示 12%。

## 仍在的可读性问题

1. `KnowledgeIngestionWorker.poll` 仍把领取、计数、提交和许可归还写在同一个回调里。执行器已关闭时，任务会先进入在途表，提交失败后留在表里，续租还能看到它；失败计数和已领取计数会一起增加。`catch` 只接住 `RuntimeException`，`Error` 会把许可留在外面。
2. `PortfolioPositionProjector.sell` 在份额校验通过后仍保留“当前份额为零则结转额为零”的分支。当前置条件成立时走不到。阅读时会误以为存在零份额赎回。
3. 投影用可变累计对象按字段副作用推进。卖出成本先按 8 位小数分配，剩余成本再收成 4 位，两套精度要同时记住。
4. 货币加权收益率用 `double` 做净现值，现金流本身是 `BigDecimal`。二分固定 200 次，超出容差直接返回空，不给出接近值。日期重复不会被拒绝。
5. 年化、波动和夏普走 `double`，其余指标走 `BigDecimal`。只有一个收益时样本标准差出现 `0/0`，要到外层才变成 `INVALID_NUMERIC_RESULT`。
6. `CalculationContext` 不检查交易日数、最小样本和无风险利率。交易日数为 0 时年化波动是有限的零；为负时才是无效数值。时钟为 null 要到读取计算时刻才失败。
7. `TimeWeightedReturnCalculator.SubPeriod` 不要求止日晚于起日。日期颠倒仍按金额连乘。
8. `PortfolioConcentrationCalculator` 的状态是字符串，不是 `MetricStatus`。null、零和负市值被静默丢掉。权重先保留 8 位再平方，合计不一定是 1。
9. `MetricValue.available` 不拒绝 null 数值。`FundMetrics`、`FundMetricSnapshot`、`FundMetricCacheKey`、`DrawdownPeriod` 也不校验 null 组件，非法组合要到使用处才暴露。
10. 两个调度器都只在用例返回非空结果后打成功日志。净值同步用私有持有类保存上海时区，快照调度用静态常量，写法不一致。二者都不接收调用方区间，空序列和非法起止日没有入口。
11. 指标缓存和快照仓库只有接口。null 键、未命中和覆盖写入的具体失败方式要到实现里才能看见，实现不在这两个模块。

## 失败路径测试

已覆盖且没有改生产代码：

- 指标计算：空序列、null 序列、null 上下文、null 时钟、区间过短、单点样本标准差无效、交易日数为负或零、重复计算
- 净值序列：null 组件、起止颠倒、越界、重复日期、空观测、起止同一天
- 净值观测：null、零、负数
- 覆盖率：预期交易日小于等于零，以及 0.98、0.90 阈值
- 持仓投影：null、空列表、null 元素、零份额买入、未拆分冲正、重复投影
- 货币加权：null、空、单笔、同号、全零、端点净现值同号、非有限金额、null 现金流
- 时间加权：null、空、价值缺失、期初不大于零、增长因子不大于零、日期颠倒仍计算、重复计算
- 集中度：null、空、全 null、非正市值、重复计算
- 净值同步和快照调度：用例抛错、结果为 null、用例为 null、重复触发
- 知识入库工人：空领取、领取失败、仓库为 null、许可占满、处理失败后归还许可、空闲与在途续租、关闭后提交失败仍留在途、并发小于 1 仍按一个许可

未单独补测试的部分：

- 缓存和快照仓库没有实现，无法在本模块断言 null 或重复写入
- 纯数据记录和枚举没有独立失败行为，失败都发生在序列、覆盖率或计算器里
- 没有启动 Spring 去触发 `@Scheduled`
- 货币加权“二分 200 次仍不收敛”没有稳定夹具；无解路径覆盖的是同号、端点同号和非有限金额
